# Supervisor Checklist

- [ ] Scope is clear and split into small issues.
- [ ] Dependency order is known.
- [ ] Each implementation worker has one issue and one branch.
- [ ] Review workers are independent from implementation workers.
- [ ] Correction workers only address accepted findings.
- [ ] Validation ran fresh checks.
- [ ] Risks were converted into follow-up issues.
- [ ] PRs are merged in dependency order.
- [ ] Final handoff includes what changed, verification, and next steps.
